API routes for the room unit group feature.

- Auth: `requireWebAuth`
- Permission: `room:view:any`
- Controller: `RoomUnitGroupController`

### PUT /:id

- Auth: `requireWebAuth`
- Permission: `room:edit:any`
- Controller: `RoomUnitGroupController`

### DELETE /:id

- Auth: `requireWebAuth`
- Permission: `room:edit:any`
- Controller: `RoomUnitGroupController`
