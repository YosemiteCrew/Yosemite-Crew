This index lists the Yosemite Crew backend REST API, split by router (one page per feature area). Base paths reflect the registration in `apps/backend/src/routers/index.ts`. For how the server itself boots and models data, see the [Backend App README](/apps/backend).

All 140 routers registered in `apps/backend/src/routers/index.ts` have a page below. The 104 added in the 2026-09 documentation pass were each checked directly against their router, controller, and validation-schema source; pages predating that pass have had only the inaccuracies found in passing corrected (for example, `appointment.md`'s `patientId`/`companionId` mismatches) rather than a full re-audit. The router source is always the tiebreaker.
