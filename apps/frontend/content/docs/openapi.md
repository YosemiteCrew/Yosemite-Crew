OpenAPI is the standard, machine-readable format for describing a REST API (its endpoints, parameters, and response shapes). This page renders the Yosemite Crew backend OpenAPI spec as a browsable reference. The viewer is Redoc, which is read-only: it has no "try it" console, so requests are not sent from this page. To run the API-key read operations under `/v1/developer` against the live API, sign in to the developer portal and open the API playground (`/developers/playground`). For a per-router breakdown of the same API, see the [Backend API Index](/apps/backend/api). The spec is located at `apps/frontend/public/static/openapi/openapi.yaml`.
