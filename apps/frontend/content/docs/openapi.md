OpenAPI is the standard, machine-readable format for describing a REST API (its endpoints, parameters, and response shapes). This page renders the Yosemite Crew backend OpenAPI spec as a browsable reference. The viewer is Redoc, which is read-only: it has no "try it" console, so requests are not sent from this page. for a per-router breakdown of the same API, see the [Backend API Index](/apps/backend/api). The spec is located at `apps/dev-docs/static/openapi.yaml`.
